# Presentationer

Superintelligents presentationer, en mapp per presentation. Designen och arbetssättet beskrivs i skillen `.claude/skills/superintelligent-presentation/SKILL.md`, och mallen ligger bredvid den i `mall.html`.

```
kund/          Möten och workshops med en kund
forelasning/   Föreläsningar, konferenser, webbinarier
akademi/       Kursmaterial till Superintelligent Akademi
intern/        Internt i teamet
exempel/       Mallen ifylld
```

Mappen byggs inte och publiceras inte på sajten. En presentation öppnas direkt i webbläsaren.
